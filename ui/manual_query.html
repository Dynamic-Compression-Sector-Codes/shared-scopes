Overview

The VOBB Timing Tool reads four inter-channel delay measurements from a single Tektronix oscilloscope over TCP/IP and writes the values into fixed cells in an Excel template. It is designed for VOBB timing shots where the delays between channels (CH1→CH2, CH2→CH3, CH3→CH4, CH1→CH4) are recorded shot-by-shot into a structured spreadsheet.

The tool connects directly to the scope’s LAN port — no GPIB adapter or front-panel interaction is needed after the scope is initially configured.

Prerequisites

  • Microsoft Excel — required for auto-detect and write features (COM interface).
  • VISA driver (optional but recommended) — NI-VISA or Keysight IO Libraries for fast waveform transfer. The app falls back to pyvisa-py automatically if no native driver is found.
  • Conda environment — managed automatically by the launcher (run-scope-query.bat).

Launching

Double-click run-scope-query.bat in the repository folder. On first run it:

  1. Pulls the latest code from GitHub.
  2. Creates or updates the scope_control Conda environment.
  3. Installs xlwings and pywin32 if missing.
  4. Creates a VOBB Timing Tool shortcut on your Desktop.
  5. Starts the application.

Use the Desktop shortcut for all subsequent launches.

Step-by-Step Workflow

1. Enter the Scope IP

Type the oscilloscope’s IP address into the Scope IP field. The last-used address is remembered and restored automatically on the next launch. Find the IP on the scope under Utility → I/O → LAN.

2. Pull Measurements

Click Pull Measurements. The tool connects over TCP/IP and reads MEAS1–MEAS4 (value, units, and measurement type). Results appear in the text area: 

Connected: TEKTRONIX,MSO54,C012345,CF:91.1CT FV:1.24.0.5874

MEAS1 (DELay): 1.234e-08 s
MEAS2 (DELay): 9.870e-09 s
MEAS3 (DELay): 1.102e-08 s
MEAS4 (DELay): 3.321e-08 s

After a successful pull, the Excel save controls appear below the buttons.

3. Save to Excel

See Excel Output below for full details. In brief:

  1. If an Excel workbook with VOBB anchor cells is already open, it is selected automatically.
  2. Otherwise click Select output .xlsx to browse.
  3. Click Save to …\filename.xlsx to write the values.

4. Show Waveform (optional)

Click Show Waveform at any time to fetch all four channels and open the waveform plot. See Waveform View for details. This step is independent of pulling measurements.

Waveform View

Fetches the full waveform record from all four channels and displays them in a live, interactive plot window.

  • All channels are shifted so the 50% falling edge of CH1 is at t = 0.
  • A dashed yellow vertical line marks t = 0.
  • Additional vertical lines mark each measured delay, colored to match the delayed channel.
  • The horizontal axis is auto-zoomed to the region of interest, using the average inter-channel delay as padding.
  • Pan and zoom interactively by clicking/dragging and scrolling.
ChannelColorTiming line position
CH1 Yellow t = 0 — reference (50% falling edge)
CH2 Cyan MEAS1 (CH1 → CH2 delay)
CH3 Pink MEAS1 + MEAS2 (CH1 → CH3 sequential)
CH4 Green MEAS1 + MEAS2 + MEAS3 (CH1 → CH4 sequential)
and MEAS4 (CH1 → CH4 direct) — dashed
Note: Waveform fetch takes several seconds per channel due to full-record transfer over TCP/IP. The button label updates to show which channel is currently being fetched.

Excel Output

Auto-detect

On startup and after each Pull Measurements, the tool scans all open Excel workbooks (up to 5) for VOBB anchor cells. If exactly one workbook contains the anchors, it is selected automatically and the save button activates — no manual selection needed.

Auto-detect is skipped if Excel is not running or more than 5 workbooks are open.

Manual selection

Click Select output .xlsx. The dialog opens to the last-used directory. The selected path is persisted across sessions.

How values are written

The tool searches the first sheet for anchor text cells. The labeled-row layout takes priority if both patterns are present.

Anchor textValue written toMeasurement
1 to 2Cell immediately to the rightMEAS1 — CH1→CH2 delay
2 to 3Cell immediately to the rightMEAS2 — CH2→CH3 delay
3 to 4Cell immediately to the rightMEAS3 — CH3→CH4 delay
1 to 4Cell immediately to the rightMEAS4 — CH1→CH4 direct delay
VOBB (fallback)4 cells directly below, one per measurementMEAS1–4 in order

If target cells already contain data, a confirmation dialog asks before overwriting. If no anchor text is found, a warning is shown and nothing is written.

Note: Anchor text is case-sensitive and must match exactly — no extra spaces. Values are written as raw numbers (seconds); formatting is controlled by the Excel template.

Scope Measurement Setup

The scope must have four delay measurements configured before pulling. On a Tektronix MSO/DPO, press Measure on the front panel and configure MEAS1–4 as follows:

SlotMeasurement typeSource (delayed)Reference
MEAS1DelayCH2CH1
MEAS2DelayCH3CH2
MEAS3DelayCH4CH3
MEAS4DelayCH4CH1

The tool reads whatever value is in each slot — it does not reconfigure the scope. Only DELay and PHAse measurements are plotted as timing markers in the waveform view; other types are still read and saved.

Troubleshooting

“VOBB timing cells not found in selected .xlsx”

The workbook does not contain the expected anchor text on the first sheet. Confirm that cells with the exact text VOBB, 1 to 2, 2 to 3, 3 to 4, or 1 to 4 exist. Text must match exactly (case-sensitive, no extra spaces).

Auto-detect does not find the workbook

Auto-detect is skipped when Excel is not running or when more than 5 workbooks are open. Use Select output .xlsx to set the path manually.

Connection timeout / scope not found

Verify the IP address is correct and the scope is powered on with LAN enabled. Default timeout is 10 seconds. Check the scope’s LAN settings under Utility → I/O → LAN.

Import error for xlwings or win32com

These are installed automatically by the launcher. If running the script directly:

pip install xlwings pywin32

Conda not found at launch

Ensure Miniconda or Anaconda is installed, then run once from an Anaconda prompt:

conda init powershell

Restart your terminal and try again.
